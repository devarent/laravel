# Contributing

Thanks for your interest in improving this repository.

## Getting started

1. Fork the repository and create a topic branch from the default branch.
2. Make focused changes and keep commits small.
3. Run the available checks locally before opening a pull request.
4. Open a pull request with a short description of the change.

## Pull request guidelines

- Keep changes scoped to a single concern.
- Update documentation when behavior changes.
- Be respectful and constructive in reviews and discussions.

## Code of conduct

By participating you agree to follow the Code of Conduct in CODE_OF_CONDUCT.md.

## Security

Do not report security issues in public. See SECURITY.md.
