# Security Policy

## Supported versions

Only the latest default branch is actively maintained.

## Reporting a vulnerability

Please do not open a public issue for security problems.
Report them privately to the repository owner via GitHub Security Advisories
or by contacting the maintainer directly. Include a description, steps to
reproduce, and the affected version or commit.

You should receive an acknowledgement within a reasonable timeframe. Please
allow time for a fix before any public disclosure.
